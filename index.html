Code Scan Alone
A code can identify or link to product information, but the code alone does not prove that the physical pack is authentic. Stronger verification needs additional evidence.
Dawai Sahi Hai
We combine batch reference data, scan activity and community reports. Anomalies can trigger a review; a scan result is not a laboratory or regulatory authenticity certificate.
How It Works

Three signals, interpreted together

No single signal proves authenticity. Together, these signals provide additional evidence for screening and review.

Database Match
Each scan is compared with the available reference database. In a production system, batch records would be supplied and validated by participating manufacturers or authorized regulatory sources.
Scan Volume Anomaly
When scan activity appears inconsistent with the expected batch volume, the system can flag the batch for investigation. This is an anomaly signal, not proof of counterfeiting.
Community Reports
Community reports can feed the prototype alert view and, in a production system, be routed for verification and regulatory follow-up.
